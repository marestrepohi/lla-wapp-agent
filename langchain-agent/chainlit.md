# Agente LLA

Asistente local de demostración. Puedes conversar libremente, consultar perfiles ficticios de QA
escribiendo el ID en el chat (sin seleccionar cliente) o preguntarle por páginas web indexadas. Si
`WHATSAPP_QA_ID_LINKING=true`, un ID desconocido genera un expediente simulado persistente en SQLite.
